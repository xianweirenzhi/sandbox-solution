# sandbox-solution

> 多板卡固件项目集合。本文档由 Claude Code 维护，随仓库变更同步更新。最后更新：2026-09-05

## 仓库结构

每块开发板 / 每个实验项目独立一个顶层目录（`<板卡>-<序号>`），互不干扰，避免上传冲突：

| 目录 | 板卡 | 说明 |
| --- | --- | --- |
| [esp8266-1/](esp8266-1/) | Adafruit HUZZAH ESP8266 | SoftAP 开放热点 + 内置 ESP8266 介绍页 + 连接自动跳转（强制门户） |
| [F8266-1/](F8266-1/) | Adafruit HUZZAH ESP8266 | esp32-1 主机的 TCP 从机：WiFi STA 联网（默认网络直连 + 同名配置热点兜底 + 断线自愈）+ 主机通信层（UDP 广播**动态发现主机 IP**、上报上线、`@命令/` 帧收发，命令内容留扩展口）；业务层智慧农场起步：0.96" OLED 状态屏激活（后续做子系统状态可视化） |
| [esp32-1/](esp32-1/) | 4D Systems gen4-ESP32S3 (R8N16) | 主机：STA（DHCP/固定 IP，超时切 AP 兜底）+ 设备状态网页 + 6 路 TCP 从机通信端口（F8266-x 上下线/掉电管理）+ **UDP 广播宣告**供从机动态发现 |

> 新板卡项目请在仓库根新建同级目录（如 `esp32-1/`），并在此表登记。

## 开发环境

- Windows 11 + VSCode（PlatformIO IDE 扩展）
- PlatformIO Core（`~/.platformio/penv/Scripts/pio.exe`）

```bash
pio run -d esp8266-1              # 构建指定项目
pio run -d esp8266-1 -t upload    # 烧录指定项目
pio run -d F8266-1                # 构建 F8266-1（HUZZAH WiFi STA 联网从机项目）
```
