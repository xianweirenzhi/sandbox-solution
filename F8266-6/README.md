# F8266-6：ESP8266（Adafruit HUZZAH）差异化气象从机（F8266-2 同构克隆）

> 本文档由 Claude Code 维护，随项目变更同步更新。最后更新：2026-09-10

## 项目概述

由 [F8266-2](../F8266-2/) 于 2026-09-10 **同构克隆**而来——沙盘从机扩展（第 6 台，六从机满编之一），接入现行主机 [esp32-2](../esp32-2/) 的 **8005 端口**。固件功能与 F8266-2 **完全一致**：GY-39 气象二合一（直连芯片直读 BME280+MAX44009）/ 土壤湿度 AO→滤波原始值 0~1023 上报（湿/干判定在主机）/ SGP30 空气质量 / 执行器（水泵/风扇/舵机）/ OLED 状态屏 / 主机 TCP 链路与 2s JSON 上报。

**即插即用**：未接线的传感器自动显示 ERR / 上报 null，不阻塞启动（探测 + 10s 热插拔重扫）；按手头硬件接到什么跑什么。后续按本机定位差异化改造时参照 [ARCHITECTURE §8.1](../ARCHITECTURE.md)。

## 与 F8266-2 的差异（仅此三处）

| 项 | F8266-2 | F8266-6 |
| --- | --- | --- |
| 设备身份 `NET_DEVICE_NAME`（STA 主机名/配置热点名/上线帧/OLED 标题自动派生） | `"F8266-2"` | **`"F8266-6"`** |
| 主机监听端口 `NET_HOST_PORT` | 8001 | **8005** |
| 构建环境名（platformio.ini） | `f8266_2` | **`f8266_6`** |

MAC 地址出厂每片唯一，克隆不产生冲突；网络参数（默认 WiFi / 主机回退地址）集中在 [src/net_config.h](src/net_config.h)。

## 详细文档

接线表、功能说明、通信协议、参数标定等同构内容**以 [F8266-2 README](../F8266-2/) 为基准**，不在本 README 重复维护；涉及全部同构从机的功能变更先行落于 F8266-2，再同步克隆（或按需差异化）。

## 构建与烧录

```bash
pio run -d F8266-6                 # 构建
pio run -d F8266-6 -t upload       # 烧录（烧录全程水泵安全：GPIO0 拉低=泵关）
pio device monitor                  # 串口监视（115200）
```

烧录前确认 [src/net_config.h](src/net_config.h) 的默认网络凭据为本机实际 WiFi（仓库提交版为占位值；也可烧录后连接同名配置热点 `F8266-6`（192.168.4.1）改配）。
